# Contributing

1. Keep model-derived outputs and manually entered metadata clearly distinct.
2. Never add fabricated parking counts, synthetic stock-photo thumbnails, or a fake connected/live status.
3. Add API validation and tests when introducing new inputs.
4. Keep new external download sources finite and curated; do not add arbitrary URL fetching.
5. Document licensing/provenance for any model weights, dataset, image, video or font added.
6. Run backend tests and a frontend production build before submitting a change.
